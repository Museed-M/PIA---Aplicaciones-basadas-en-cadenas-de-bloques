¿Conectar tu wallet?

TicketChain es una aplicación descentralizada. Para comprar, revender o validar boletos necesitas conectar una wallet de software como MetaMask, Phantom o similar.

Si decides no conectar, podrás explorar la app en modo solo lectura: verás los eventos disponibles pero no podrás realizar ninguna transacción.
